FMZFaruk's Movie ZoneOne-time Dropbox setup

1Create a Dropbox app

  • Open dropbox.com/developers/apps/create (log in with the Dropbox that has your movie folder).
  • Choose Scoped access → Full Dropbox → name it e.g. FMZ Sync → Create app.
  • Open the Permissions tab and tick: files.metadata.read, files.content.read, sharing.read, sharing.write → Submit (at the bottom).
  • Open the Settings tab and copy the App key and App secret into the boxes below.

2Allow access

Press the button, click Continue and Allow in Dropbox, then copy the code it shows and paste it here.

3Save the three values in GitHub

  • On GitHub open your movie repository → Settings → Secrets and variables → Actions → New repository secret.
  • Add three secrets with these exact names:
    DROPBOX_APP_KEY → your App key
    DROPBOX_APP_SECRET → your App secret
    DROPBOX_REFRESH_TOKEN → the token made in step 2

4Start the first sync

  • Open the Actions tab of the repository. If asked, press I understand… enable them.
  • Click Sync movies from Dropbox → Run workflow → Run workflow.
  • The first run downloads each movie once to read its subtitles, so it can take 10–30 minutes. After that it runs by itself every 15 minutes and only works on new files.

Nothing you type here is saved or sent anywhere except to Dropbox.
